### Các lệnh hữu ích:
- `npm start`: Khởi động máy chủ phát triển cục bộ (port 4200)
- `npm test -- --watch=false --browsers=ChromeHeadless`: Chạy 27 bài kiểm thử đơn vị độc lập
- `npm run build:prod`: Biên dịch bản phát hành sản xuất với fileReplacements
- `npm run scan:bundle`: Quét an ninh và kiểm tra rò rỉ dữ liệu nhạy cảm (Zero-PII)

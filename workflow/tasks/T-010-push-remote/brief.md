# Đề bài (Brief) - Việc T-010

- Tên việc: Đẩy toàn bộ mã nguồn lên kho Git chính thức (mayday-test)
- Mục tiêu:
  1. Kiểm tra toàn bộ trạng thái git sạch (`git status`).
  2. Đẩy nhánh `main` lên repository từ xa: `https://github.com/hazeth-htt/mayday-test.git`.
  3. Đảm bảo toàn bộ commit history, tags, và workflow báo cáo được đồng bộ hoàn hảo.
- Tiêu chí nghiệm thu:
  - `git push -u origin main` thành công không xung đột.
  - Nhánh `main` trên remote GitHub phản ánh đầy đủ trạng thái production-ready.

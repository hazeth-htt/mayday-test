# Design Spec — T-019 Full Visual Polish

## 1. Thành phần Hero Gradient
- `.base-hero`: Gradient từ `--base-brand-navy` (#091f5b) đến #1e3d8f với radial highlight tinh tế.
- Action buttons trên hero: `.base-btn-hero-primary` (ghost kính mờ) và `.base-btn-hero-accent` (trắng nổi bật).

## 2. Thẻ Chỉ Số KPI (Stat Cards)
- `.base-stat-card`: Thẻ chỉ số sắc nét, số liệu lớn cỡ 2rem font-bold, thanh chỉ báo gradient xuất hiện khi hover.

## 3. Hệ Thống Biểu Tượng
- Sidebar & Header: 100% dùng font vector Iconsax (`.isax` / `.isax-b`). Tuyệt đối 0 SVG inline.

## 4. Empty State
- `.base-empty-state`: Biểu tượng trung tâm, tiêu đề và giải thích rõ ràng cho người dùng.
